# 🍬 Jelly Price Checker

상품명 기준으로 쿠팡·네이버 최저가를 자동 수집하는 Windows 데스크탑 프로그램.

---

## 설치 방법 (개발/소스 실행)

```bash
pip install -r requirements.txt
playwright install chromium
```

## 실행 방법 (소스에서 직접 실행)

```bash
python main.py
```

---

## exe 빌드 방법

> **빌드 PC** 에서 아래 배치 파일을 실행합니다. 빌드 PC에는 Python과 인터넷 연결이 필요합니다.

```bat
build_exe.bat
```

빌드가 완료되면 `dist\JellyPriceChecker\` 폴더가 생성됩니다.

### 배포 구조

```
dist\JellyPriceChecker\
    JellyPriceChecker.exe       ← 실행 파일
    browsers\
        chromium-XXXX\          ← Chromium 브라우저 (자동 포함)
            chrome-win\
                chrome.exe
    ...기타 라이브러리 파일...
```

### 배포 방법

`dist\JellyPriceChecker\` **폴더 전체**를 대상 PC에 복사하세요.

대상 PC에서 `JellyPriceChecker.exe` 를 실행하면 됩니다.

- Python 설치 불필요
- `playwright install chromium` 불필요
- Chromium 브라우저가 폴더 안에 포함되어 있습니다

> **주의:** `JellyPriceChecker.exe` 파일만 단독 복사해서는 동작하지 않습니다.
> 반드시 `dist\JellyPriceChecker\` **폴더 전체**를 복사해야 합니다.

## 엑셀 입력 양식

| A열 (상품코드) | B열 (상품명) |
|---|---|
| A001 | 지오마 화이트머스크 600g |
| A002 | 마르마르디 네롤리 핸드크림 50ml |

- 1행은 헤더일 수도 있고 아닐 수도 있음 (GUI에서 선택)
- 빈 상품명 행은 자동으로 건너뜀
- 상품코드는 결과에 그대로 표시만 하며 검색에는 사용하지 않음

## 결과 엑셀 컬럼 설명

| 열 | 설명 |
|---|---|
| 상품코드 | 입력 상품코드 그대로 |
| 상품명 | 입력 상품명 그대로 |
| 쿠팡가 | 쿠팡 검색 최적 상품 판매가 |
| 쿠팡배송 | 쿠팡 배송비 (무료=0, 미확인=빈칸) |
| 쿠팡합계 | 쿠팡가+배송비 (배송비 미확인 시 빈칸) |
| 스스가 | 네이버 스마트스토어 판매가 |
| 스스배송 | 스마트스토어 배송비 |
| 스스합계 | 스스가+배송비 |
| 네최몰 | 네이버 최저가 판매처 |
| 네최가 | 해당 판매처 가격 |
| 네배송 | 해당 배송비 |
| 네합계 | 네최가+배송비 (배송비+가격 모두 확인된 것끼리만 비교) |
| 비고 | 확인불가/배송비확인불가/수동확인필요 등 상태 메모 |
| 쿠팡링크 (숨김 열) | 쿠팡 상품 링크 — 열 숨기기 해제 후 확인 가능 |
| 스스링크 (숨김 열) | 스마트스토어 링크 |
| 네최링크 (숨김 열) | 네이버 최저가 링크 |

## 주의사항

### 검색 차단 및 캡차

- 쿠팡·네이버가 봇 탐지 또는 캡차를 표시하면 해당 상품은 **"쿠팡 확인불가" / "네이버 확인불가"** 로 처리됩니다.
- 캡차·로그인·차단을 자동으로 우회하는 기능은 포함되어 있지 않습니다.
- 차단이 발생하면 잠시 후 다시 시도하거나, GUI 설정에서 딜레이를 늘려보세요.

### 배송비

- 배송비가 화면에서 확인되지 않으면 배송비·합계 칸은 빈칸으로 처리됩니다.
- 비고 칸에 "배송비 확인불가" 로 기록됩니다.

### 사이트 HTML 구조 변경

- 쿠팡·네이버 사이트의 HTML 구조가 바뀌면 파싱이 실패할 수 있습니다.
- 이 경우 `config.py`의 `SELECTORS` 딕셔너리를 업데이트하면 됩니다.
- 별도 코드 수정 없이 selector만 변경하면 되도록 설계되어 있습니다.

### 브라우저 headless 설정

- 기본값은 **브라우저 표시(headless=OFF)** 입니다. 검색 과정을 눈으로 확인할 수 있습니다.
- GUI 설정에서 "브라우저 숨기기"를 체크하면 백그라운드로 실행됩니다.
